Code signing policy

Trusted releases

Official Windows releases are built from the public source repository by GitHub Actions. The release workflow verifies Authenticode signatures and SHA-256 checksums before publication.

Signing provider

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Team roles

Committer and reviewer: Henner4746
Release approver: Henner4746

Multi-factor authentication is required for every repository and signing role. Outside contributions require maintainer review. Every signing request requires explicit release approval.

Privacy and system changes

The app transfers selected media only when the user explicitly configures Google Photos synchronization. It has no telemetry, advertising, or own backend. See the privacy policy.

The installer announces its installation path and autostart behavior and provides a normal Windows uninstaller.

Verification

Download only from the official releases page. Each release includes SHA-256 checksums. The Windows signature can be inspected in the file properties.
